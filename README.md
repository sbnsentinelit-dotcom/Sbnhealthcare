# SBN Healthcare

Fullstack repository containing the backend and frontend for SBN Healthcare Solutions (US & English Edition).

## Project Structure

```
Sbnhealthcare/
├── backend/    # Node.js / Express API server
└── frontend/   # Next.js 16 / React 19 Frontend application
```

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
